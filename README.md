# Lake Monitoring System

A real-time lake monitoring system that detects plastic waste, analyzes water quality, and generates automated reports using computer vision and machine learning.

---

## Features

- Plastic detection using computer vision  
- Water quality prediction (pH, turbidity, dissolved oxygen, etc.)  
- Real-time monitoring from live camera feed  
- Automated report generation with:
  - Detection time  
  - Location  
  - Water quality metrics  
- User notifications when plastic is detected
